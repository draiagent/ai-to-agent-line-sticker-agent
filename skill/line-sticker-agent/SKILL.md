# LINE 貼圖製作與驗收上架

## 輸入與工具
讀取使用者提供的VAC與最多8張參考圖片、貼圖用語及靜態或動態選擇。未指定類型時只詢問這項必要選擇。保留原圖，少於8張可先製作樣板，批次的用語與構圖依使用者意圖補齊。
需要讀圖、圖像生成或編輯、檔案處理與APNG編碼能力；工具由執行Agent依環境選擇。本技能是工作指引，不是獨立模型。

## 執行

1. **素材解析**：辨識角色、畫風與貼圖用語；保留高解析原圖，確認素材權利。
2. **構圖精簡**：放大角色與文字，減少細碎配件；以聊天大小檢查清晰度與辨識度。
3. **乾淨分層**：分離文字與底圖，清除原字殘留；真透明去背，去除外圍白邊與雜點。
4. **樣板先行**：先做一張，預覽確認後再批次；人物、寵物、物品保持靜止。
5. **文字動畫**：文字明顯彈跳、縮放，保持完整；每格從原始圖層生成，避免反覆縮放。
6. **畫質驗收**：深淺背景逐格檢查白邊與殘影；實際播放APNG，修正模糊與閃爍。
7. **批次製作**：套用合格樣板，生成8張同系列；附主要圖片、標籤圖，逐檔查核規格。
8. **交付上架**：交付ZIP、預覽、文案與驗收表；依LINE最新規定檢查；授權後上傳送審。

類型未指定時確認靜態或動態；使用者確認樣板且畫質驗收通過後才批次。發現模糊、白邊、殘影時，自行回到分層或構圖修正，再重測。登入由使用者完成，送審前確認。

## 驗收
文字完整清晰，風格一致，真透明；動畫以文字為重點，第一格可獨立閱讀。檢查尺寸、容量、畫格、播放次數和總時長，以及素材權利與內容規定。技術檢查、人工視覺檢查、實際上傳、送審、審核結果分開記錄。

## 輔助程式
完整Repo的scripts/sticker.py可縮放靜態圖、將已製作畫格編成APNG、檢查單張貼圖與打包PNG。它不負責產生角色、分層、主要圖片或平台上傳；這些工作由Agent調用適合工具完成。不可將預覽GIF當作LINE上傳檔。

## 白邊驗收

外圍不得有白色貼紙描邊、白色霧邊或假透明棋盤格。保留衣物、杯子及毛色本身的白色；不可直接刪除全部白色像素。分別在白、深灰與聊天背景上檢查，動畫逐格檢查閃爍、殘影及白邊。透明留白與不透明白邊必須區分。

## 畫格合成規則

每格從同一乾淨底圖與原始高解析文字層重新合成，不沿用上一格已縮放或已合成圖片。底圖不可殘留原文字、陰影或裝飾碎片；文字遮罩不可切到頭髮或角色。編碼後重新解碼APNG，比對每格透明區域與預期畫面，檢查blend/disposal造成的累積殘影。輸出前只縮至目標尺寸一次。

以正式APNG驗收，GIF僅為分享預覽，不用GIF判定正式檔畫質。容量與尺寸通過不代表視覺合格；未通過的樣板不得用於批次。
