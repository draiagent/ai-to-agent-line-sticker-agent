# 第一批八張：交給 Agent 的任務

請依附件 VAC 和角色參考圖片，製作一批 8 張靜態 LINE 貼圖。
文字依序：早安、晚安、下班、辛苦了、ok、sorry、哈哈、謝謝。

角色：賽博龐克玻璃果凍科技貓，藍紫色、圓潤無毛、發光電路；文字有立體感，動作配合語意。
先做早安一張確認，之後完成本批。透明背景、沒有外圈白色描邊；禁止多手、殘字與假透明背景。每張在聊天大小及深淺底檢查。
請查核 LINE 官方最新規格，完成尺寸、檔名、容量與留白整理，交付圖片 ZIP、預覽、商品文案與驗收表。發現問題自行修正後複驗。

若改為動態：文字須有清楚動畫，角色與道具靜止；以原始圖層逐格輸出並實播 APNG，檢查殘影、模糊與閃爍。

本範例只處理 8 張貼圖。main／tab 另開配套任務；準備上架時再共同驗收。

教學評量：8 句正確、角色一致、動作合理、透明邊緣乾淨、格式符合當次規定、可核對驗收紀錄；任一失敗都須修正。這是示範任務，非本次執行結果。
