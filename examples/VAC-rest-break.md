# 實測案例：休息一下

文字固定為繁體中文「休息一下」。米色西裝人物坐在橘色沙發，配角為貓咪，白色咖啡杯不帶Logo。

第一版蒸氣等微動畫不明顯；修正後集中讓文字彈跳及縮放，人物、寵物、物品保持靜止。

- static.png：靜態樣板。
- animated.png：16格、2秒、播放1次的APNG。
- preview.gif：方便閱讀的循環預覽，不是上傳檔。

本案例只有單張樣板，未組成8張套組，未附主要圖片與標籤圖，未實際上傳或送審。

## 白邊修正

使用者指出前版外圍白色描邊會出現在對話背景。static.png、animated.png、preview.gif保留作為已知問題的回歸案例，不是可上架成品。borderless-source.png為新增去除白色外描邊的透明原圖；已重建為borderless-static.png與borderless-animated.png；borderless-preview.gif為分享預覽。使用者仍反映畫質不佳與殘留，視覺驗收未通過。不可將技術檢查通過解讀為可上架。
