# 上架前驗收清單

規格查核日：2026-11-01；每次上架重新查核官方原文。

| 項目 | 靜態 | 動態 |
|---|---|---|
| 本任務套組 | 8張 | 8張 |
| 貼圖尺寸上限 | 370×320 | 320×270，至少一邊270以上 |
| 主要圖片 | 240×240 PNG | 240×240 APNG |
| 聊天室標籤圖 | 96×74 PNG | 96×74 PNG |

- 使用真透明PNG、RGB/RGBA；靜態偶數尺寸、72dpi以上，留白約10px。
- 單檔採小於1,000,000 bytes的保守檢查，ZIP小於60MB。
- 逐張檢查文字、裁切、殘影、角色一致與實際播放；第一格能清楚表意。
- 素材、肖像、商標、版權與貼圖用語需依官方審核準則覆核；技術通過不能取代內容審查。
- 驗收表記錄：檔名、檢查項目、通過/失敗/未驗證、證據、修正結果。
- 狀態依序分開：已製作、已技術檢查、已視覺檢查、已上傳、已送審、已核准。

## 白邊驗收

外圍不得有白色貼紙描邊、白色霧邊或假透明棋盤格。保留衣物、杯子及毛色本身的白色；不可直接刪除全部白色像素。分別在白、深灰與聊天背景上檢查，動畫逐格檢查閃爍、殘影及白邊。透明留白與不透明白邊必須區分。

## 畫質與殘影

在實際聊天大小確認臉部清楚、文字可讀、角色比例一致。播放正式APNG並逐格檢查原字殘留、遮罩切邊、動畫累積、邊緣閃爍；不合格則回到分層及構圖重做，樣板合格才批次。GIF色彩與透明呈現不作正式檔驗收依據。
