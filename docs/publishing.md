# 上架工作流程

1. 登入 LINE Creators Market 並完成創意人註冊。
2. 建立正確貼圖類型；確認本次官方允許的張數與檔案規格。
3. 填寫英文預設名稱與說明，加入繁體中文版本；據實標示使用 AI。
4. 另製並檢查主圖 main 與標籤圖 tab，與貼圖一起打包上傳。
5. 用不同背景預覽，確認圖片對應、去背、可讀性；動態版必須實播。
6. 核對售價、地區、活動參加選項及手動／自動販售設定，再送審。
7. 審核通過後依設定啟動販售；退回則讀取原因、修正並重驗。

不保證審核時程、審核通過或銷售收益。不沿用舊影片的價格、地區與審核速度推論。涉及登入、條款與付款的操作依使用平台規則處理。
